        prisma (Classic/Stable Prisma 6)
1. Install Prisma 6 CLI and Client:
   npm i @prisma/client@^6
   npm i -D prisma@^6

2. Initialize Prisma with PostgreSQL:
   npx prisma init --datasource-provider postgresql

   Explanation:
   - Creates `prisma/schema.prisma` containing:
     * `generator client`: specifies Prisma Client generation.
     * `datasource db`: sets the database provider to `postgresql`.
   - Creates or updates `.env` with the `DATABASE_URL` template.

3. Configure Database Connection:
   In `.env`:
   DATABASE_URL="postgresql://<user>:<password>@localhost:5432/<dbname>"

npx prisma migrate dev --name creatingtable:to update something
npx prisma generate:this creates the table or if you make some change do this first 
npx prisma db push

        auth & validation (Zod + JWT + Bcrypt)
1. Install dependencies:
   npm i bcrypt jsonwebtoken zod
   npm i -D @types/bcrypt @types/jsonwebtoken

2. Request Validation Flow with Zod:
   - Define schema in `src/schema/user.ts`:
     name (min 3, max 20), email (valid email), password (min 6, max 20)
   - IMPORTANT: Validate `req.body` using `userSchema.parse(req.body)` BEFORE hashing.
     Do not validate after `hashSync()` because bcrypt produces a 60-character hash,
     which would violate the max 20 character password limit.
   - Catch `ZodError` to return HTTP 400 with specific error messages.

3. JWT Secret:
   - Import asserted `JWT_SECRET` from `src/secret.ts` into controllers to satisfy TypeScript.


        product CRUD, DAL architecture & frontend integration
1. Schema & Validation (src/schema/product.ts):
   - `createProductSchema`: name (min 2, max 100), description (min 3, max 1000), price (positive coerce number), tags (optional).
   - `updateProductSchema`: optional fields for partial or full updates.
   - `searchProductSchema`: query, minPrice, maxPrice, tag, sortBy (name/price/createdAt), sortOrder (asc/desc), pagination (page, limit).

2. DAL Pattern (src/dal/base.dal.ts & src/dal/product.dal.ts):
   - `base.dal.ts`: Updated `id` typing to support `number | string` to seamlessly work with autoincrement integer IDs.
   - `product.dal.ts`: Implemented `searchProducts()` with case-insensitive `OR` matching on name, description, tags, range filtering for price, and dynamic sorting with pagination count.

3. Service & Controller Layer (src/service/product.service.ts & src/controllers/product.controller.ts):
   - Service: Encapsulates business logic for `createProduct`, `getProductById`, `updateProduct`, `deleteProduct`, and `searchProducts`.
   - Controller: Parses request params/body with Zod schemas, delegates to service, and returns structured responses (`{ success: true, ... }`).
   - Routes (src/Routes/product.route.ts): Registered GET `/` (search/list), GET `/:id`, POST `/`, PUT/PATCH `/:id`, and DELETE `/:id`.

4. Frontend Integration (front/src/):
   - API client (`services/productApi.ts`): Axios instance pointing to `http://localhost:3000/api` with full typing for search, create, update, and delete.
   - Tailwind CSS v4 configured with `@tailwindcss/vite` in `vite.config.ts`.
   - Responsive UI (`page/Product.tsx`):
     * Real-time search by keywords or tags.
     * Filter by price ranges and sort order (ascending/descending, price/name/date).
     * Modal dialog (`ProductModal.tsx`) for adding and editing products with validation.
     * Delete confirmation dialog (`DeleteConfirmModal.tsx`) with safe rollback.
     * Pagination controls with page indicator.
